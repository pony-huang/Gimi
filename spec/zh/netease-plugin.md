# 网易云音乐插件

独立模块 `:plugins:netease`，插件 ID 为 `netease`，包名为 `github.ponyhuang.gimi.plugin.netease`。插件通过现有发现服务和 ADK 工具集接入宿主，无需 MCP 服务或中转服务。

## 配置与登录

配置页提供[网易云音乐 CLI 官网](https://music.163.com/st/ncmcli)的跳转入口；私钥输入框标签为 `Private Key`。

1. 安装网易云插件 APK，在宿主插件页填写网易云开放平台分配的 App ID 和对应 RSA PKCS#8 私钥。支持带 PEM 头尾的文本或不带头尾的 Base64（CLI 配置格式），支持实际换行或文字形式的 `\n`；不接受电脑上的私钥文件路径。
2. 点击唯一的“登录网易云”按钮。宿主自动保存当前表单，插件取得公网 IP 和匿名令牌，随后打开平台返回的 HTTPS 登录链接。
3. 在网易云客户端确认登录。插件按照官方 CLI 的方式每 3 秒轮询扫码状态，最长等待 300 秒；回到宿主时自动显示登录成功，不需要手动点击检查结果。
4. 过期或失败时再次点击登录；已授权时按钮显示重新登录。重新登录和更换凭据会取消旧轮询，设备进程退出后需重新发起未完成的登录。
5. 配置页不暴露凭证校验、匿名登录、手动检查或清除登录等调试按钮。Agent 工具仍可显式执行这些操作；清除本地登录不撤销平台授权。

登录令牌通过 `:core:security` 的 Android Keystore AES/GCM 加密后保存在宿主私有存储，按凭证身份隔离。传输使用 Android 系统 `HttpURLConnection`，插件不打包 OkHttp/Okio，避免父优先类加载引用到宿主 R8 优化后的不完整实现。设备 ID 为随机持久化值；调用官方 CLI 使用的 IP 服务获取协议必需的 `device.clientIp`，短期缓存五分钟，不写入磁盘或工具结果。空 IP 会被平台以 `2511` 拒绝。令牌、私钥、签名不进入工具结果或错误响应。

状态入口沿用通用 `oauth_status` 动作，支持 authorized / unauthorized / pending / expired；页面仅在 pending 时定期读取插件本地状态，平台轮询始终由插件负责。DNS、TLS、超时、公网 IP 获取失败、HTTP 状态码和平台业务错误码分别显示，避免统一成无法诊断的 request failed。

## 工具与能力边界

提供 24 个工具：登录状态、凭证验证、匿名登录、生成二维码、检查扫码、刷新登录、退出、用户资料、红心歌单、创建/收藏歌单分页、歌单详情、歌单歌曲分页、歌曲详情及授权 URL、批量加歌、分享短链，以及服务端动态命令清单查询、分类搜索、综合搜索、热词、搜索建议、逐行/逐字歌词、创建歌单、红心收藏与批量删歌。

- 账号资料、私人歌单列表、红心歌单、创建歌单、加歌/删歌和红心收藏操作需要扫码登录。
- 歌单分页每页 1–100 条，默认 30 条；加歌/删歌每次 1–100 个歌曲 ID，重复 ID 合并。
- 歌曲接口保留平台返回的试听、版权和 VIP 限制；获取 URL 不代表已经播放。
- `netease_commands` 使用当前登录态向 manifest 接口发送 `cli_version: "0.1.7"` 和空 `cached_versions`，查询当前 App ID 获授权的动态命令。每次读取完整清单，不缓存、不执行返回的命令；清单内容作为不可信数据处理。
- 搜索与歌词通过新版参考文档给出的官方端点直接调用，不依赖 manifest。分类搜索支持歌曲（v3）、专辑、歌手和歌单，默认每页 30 条；综合搜索、热词及搜索建议分别提供独立工具。歌词支持逐行和逐字模式，原样保留 `noLyric` 等结果，不在失败时自动重试另一接口。
- 歌曲与歌单工具使用平台结果中的 32 位十六进制加密 ID，按字符串原样传递；网页数字 ID 无法替代。歌曲详情码率使用官方枚举 `128/320/999/1999`（kbps），默认 `320`，不再传入 `320000`。
- 创建歌单发送 `playlistName`，红心操作发送 `songId` 和 `isLike`，批量加歌/删歌发送 `playlistId` 和字符串数组 `songIdList`。写操作均需要用户明确要求，不自动重试。
- 笔记发布仍只有服务端 manifest 可提供具体协议，目前仅支持清单查询。云盘上传、播放控制和播放心跳未实现。
- 歌曲详情支持显式传入 `effects`、`level`、`immerse_type` 和 `trial_scene`；值须来自已知的平台约定，不推测枚举或改变试听权限。
- 平台 `301` 表示 App ID 未获当前接口授权，需在开放平台开通，重新登录不能授予接口权限；`2511` 单独提示设备公网 IP 问题。
- 不自动重放失败业务请求。HTTP 取消会关闭连接；包括 `503 + Retry-After: 0` 在内的错误响应不会自动重试，避免重复写入。

协议依据用户提供的新版 `ncm-cli-api.md` 与 `analysis/ncm-openapi-reference.md`（包含官方文档中心提取的搜索、歌词和歌单参数），并重新读取官方歌曲搜索及歌词文档确认。基础协议依据 `ncm-cli-api.md`（`@music163/ncm-cli@0.1.7` 分析）。参考 CLI 补充确认：获取二维码前需要有效登录令牌；扫码成功的令牌位于 `data.accessToken` 对象。平台协议仍可能变化，MockWebServer 测试不等于真实账号联调。
