# API 接入设计基线

更新日期：2026-10-23。本轮在原 API 接入改版（`504e2fe1`）上统一布局和直接操作方式。云文件上传及附件行为以 [云文件与附件独立状态卡](cloud-files-and-attachment-status.md) 为准。

## 页面结构

| 页面 | 当前设计 |
| --- | --- |
| API 接入首页 | 仅显示已添加服务，副标题仅显示模型数量；每行开关立即启停，名称区域进入详情；仅右上角保留添加入口 |
| 新增服务 | 可搜索的厂商目录，选择后进入编辑；厂商目录不显示启停开关 |
| 服务详情 | 连接、模型和扩展设置使用同一份草稿，保存后统一生效 |
| 接口设置 | 在连接卡片内展开协议下拉和地址，收起后显示协议摘要；不再跳转高级连接页 |
| 管理模型 | 无搜索框；右上角刷新获取模型、加号手动添加；显示总数、已选数、全选和清空，按对话、语音识别、语音合成分组并显示数量 |
| 页内扩展能力 | 在服务详情模型区下方直接显示文件和工具卡，不设独立页面或跳转入口；文件开启后展开有效期，工具总开关与能力名称在同一卡片 |
| 服务菜单 | 保留暂停、恢复和删除入口；删除需要确认，暂停保留配置 |

## 行为约束

- 列表启停使用专用原子写入，不覆盖密钥、模型及上传/工具偏好；任务忙碌时禁止写入，待处理期间禁止同一服务重复点击。开关跟随仓库回流，失败时保留原状态并显示错误。
- 列表通过 Switch 表达状态，不重复显示“已启用/已暂停”。开关具有服务名称的无障碍标签。
- 接口设置只是展开表单，不改变默认 Chat Completions 协议。协议菜单仅显示厂商支持的选项。
- 模型类型沿用已有元数据（对话、STT、TTS）；无候选的类型不显示。全选/清空只修改待确认选择；确认才更新编辑草稿，最后保存才更新运行时。允许保存零个模型。
- 模型页返回取消未确认选择；保留模型 ID、原分组及能力信息。
- 文件上传卡仅在当前协议为 OpenAI Chat Completions 时显示，兼容厂商同样适用，与厂商是否有工具无关。Anthropic / Gemini 下即使曾开启上传也隐藏整张卡及其说明；原偏好保留，发送仍按协议规则处理。
- 厂商工具开关控制聊天工具面板入口，不自动调用工具；支持的工具名称始终可见，关闭时弱化显示。
- 文件卡保留 PDF/单次总量限制和有效期仅影响新上传文件的简短说明。
- 子页返回不另存一份配置；有未保存修改时，退出可保存、放弃或继续编辑。

## 视觉与评审

沿用 `PreferenceStyle.Compact`、现有分组卡片、主题色、间距和安全区；浅色与深色保持相同层级。评审确认后接入正式页面，保留相关 `@Preview` 状态，不引入生产预览依赖或 UI 截图测试。

本轮确认的预览图归档在 `temp/modelsettings-refinement/settings-design.zip`。原 `temp/design-review/` 中的初始改版图片仅供历史追溯。

## 动效与刷新反馈（2026-10-23）

- 接口设置以约 220 毫秒展开、200 毫秒收起，配合淡入淡出与箭头旋转；协议摘要保留，避免行高突变。
- 管理模型使用约 240 毫秒的方向性滑动和淡入；返回使用相反方向，详情滚动位置独立保留。
- 刷新成功沿用 Route 的系统短提示，显示“已获取 N 个模型”，N 为本次响应中有效且去重后的模型数量，不是累计候选数或新增数量。空响应显示零并保留页内空结果提示；失败保留现有页内错误，连接变更取消旧刷新，不发送迟到成功提示。
