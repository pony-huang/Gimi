# API 接入改版设计基线

更新日期：2026-10-22。该轮改版已实现并提交：`504e2fe1`，`feat(modelsettings): redesign API service configuration`。本文件用于解释本轮云文件功能所沿用的页面结构，不表示文件上传已经实现。

云文件新增需求以 [云文件与附件独立状态卡](cloud-files-and-attachment-status.md) 为准。

## 1. 页面结构

| 页面 | 已实现的设计 |
| --- | --- |
| API 接入首页 | 仅显示已添加服务，展示状态及已选模型数量；不铺满全部厂商 |
| 新增服务 | 进入可搜索的厂商目录，选择后进入编辑 |
| 服务详情 | 编辑连接、模型和扩展能力，修改作为草稿保存 |
| 高级连接 | 单独编辑地址、协议等连接配置 |
| 模型选择 | 搜索、获取模型、手动添加与勾选；确认后更新编辑草稿 |
| 扩展能力 | 独立管理厂商工具入口；本轮将新增文件上传设置 |
| 服务菜单 | 暂停、恢复、删除服务；删除有确认，暂停保留偏好 |

## 2. 已确认的行为

- 顶部不再使用含义模糊的服务总开关；服务状态通过菜单动作管理。
- 厂商工具设置移入扩展能力，说明其控制聊天入口，不表示自动执行工具。
- 修改配置与模型选择不立即影响运行时，显式保存后统一更新。
- 有未保存修改时，离开可选择保存、放弃或继续编辑。
- 模型子页返回取消未确认选择；允许保存零个已选模型。
- 保留模型 ID、分组及能力信息；暂停、恢复不重置已保存偏好。
- 保存连接、服务状态、已选模型和工具偏好时保持配置一致性，凭据使用安全存储。
